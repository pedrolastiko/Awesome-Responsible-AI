# Awesome Responsible AI [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

A community-driven hub centralizing frameworks, legislation, tools, research, use cases, and practical artifacts for Responsible AI.

## Repository map

- [Legislation](./legislation/) — enacted laws, proposed texts, guidelines, and enforcement tracking.
- [Frameworks](./frameworks/) — international, national, sectorial, industry, and academic RAI references.
- [Pillars](./pillars/) — 9 universal pillars to evaluate and compare RAI initiatives.
- [Tools](./tools/) — checklists, assessments, templates, and HTML artifacts.
- [Research](./research/) — papers, institutional reports, datasets, and glossary.
- [Use cases](./use-cases/) — domain-specific implementation patterns.
- [Community](./community/) — organizations, events, and collaborative initiatives.

## How to navigate

1. Start with the [9 pillars](./pillars/) to align on evaluation criteria.
2. Explore [frameworks](./frameworks/) for standards and governance models.
3. Review [legislation](./legislation/) for legal obligations and enforcement trends.
4. Apply [tools](./tools/) to operationalize controls and evidence.
5. Use [research](./research/) for deeper technical and policy grounding.
6. Adapt through [use cases](./use-cases/) and connect with the [community](./community/).
